# 画面仕様

## 目的

HEXACO-PI-R の 60問版・100問版に回答し、性格全体の因子と下位尺度を確認できる PoC です。

以前のように外向性だけへ絞る仕様は採用していません。全体構成を表示し、その中に外向性も含めています。

## 画面構成

画面は大きく4つの領域に分かれています。

- テスト切り替え: 60問版と100問版を選ぶ
- 進捗表示: 回答済み数、進捗バー、未回答への移動
- 質問パネル: 現在の質問と5件法の回答ボタン
- 結果パネル: 因子と下位尺度のスコア一覧

## 回答の流れ

1. 60問版または100問版を選ぶ
2. 質問に5件法で回答する
3. 回答すると次の質問へ進む
4. 必要に応じて質問ドットから過去の質問へ戻る
5. 結果パネルで各尺度の状態を見る

## 結果表示

結果パネルでは、下位尺度を動的に切り替えません。

すべての因子を常に表示し、各因子の下に下位尺度をすべて並べます。回答途中の尺度は進捗、回答がそろった尺度は平均スコアと解釈ラベルを表示します。

60問版では6因子を表示します。100問版では6因子に加えて、利他性も表示します。

## モバイル対応

スマホ幅では1カラム表示に切り替えます。

- 回答ボタンは指で押しやすい高さにする
- 質問文は横にはみ出さないよう折り返す
- 質問ドットは狭い画面ではスクロール可能にする
- 結果パネルは固定表示せず、質問パネルの下に自然に続ける
- 下位尺度は1列で表示する

## この PoC でまだ扱わないこと

- 結果の保存
- PDF 出力
- ユーザー管理
- 回答履歴の比較
- 診断文の詳細生成
- 医療・心理診断としての判定
