# HEXACO 性格テスト PoC

`ref` フォルダにある HEXACO-PI-R の 60問版・100問版資料をもとに、ブラウザで回答と採点を試せる PoC です。

## 何を測るアプリか

このアプリは外向性だけを測るものではありません。現在の仕様では、HEXACO の性格全体を測るテストとして実装しています。

表示する尺度は次の通りです。

- 誠実さ・謙虚さ
- 情動性
- 外向性
- 協調性
- 勤勉性
- 開放性
- 利他性（100問版のみ）

各因子には下位尺度があります。結果画面では、因子と下位尺度をすべて静的に一覧表示します。

## 現在できること

- 60問版と100問版を切り替える
- 5件法で質問に回答する
- 回答済み数と進捗を確認する
- 未回答の質問へ移動する
- 因子スコアと下位尺度スコアを見る
- 回答途中でも各尺度の回答状況を見る
- デモ回答を入れて結果表示を確認する

## データの扱い

アプリの実行時に Word ファイルや PDF を直接読み込むことはありません。

質問文、採点キー、基準値は、あらかじめ変換した `src/data/test-definitions.json` を正本として使います。`ref` フォルダのファイルは元資料として残しています。

詳しい形式は [docs/data-format.md](docs/data-format.md) にまとめています。

## 採点の考え方

回答は 1 から 5 の数値として扱います。

逆転項目は `6 - 回答値` で採点します。下位尺度スコアは対象項目の平均、因子スコアはその因子に含まれる項目の平均です。

基準値がある尺度は、平均値と標準偏差から z 得点を計算し、ざっくりと「高め」「平均付近」「低め」などの表示に変換します。

この PoC は自己理解や研究用途の参考表示を想定しています。心理・医療上の診断を行うものではありません。

## 起動方法

```bash
pnpm install
pnpm run validate:data
pnpm run dev
```

ビルド済みのファイルを確認する場合は次を使います。

```bash
pnpm run build
pnpm run serve:dist
```

通常は `http://127.0.0.1:5173/` で開けます。

## 主なファイル

- `src/App.tsx`: 画面、回答状態、採点、結果表示
- `src/styles.css`: レイアウトとモバイル対応
- `src/data/test-definitions.json`: 変換済みの質問・採点キー・基準値
- `src/data/tests.ts`: データ型と読み込み
- `scripts/validate-test-data.mjs`: データ整合性チェック
- `scripts/serve-dist.mjs`: ビルド済みファイルのローカル配信
- `docs/app-spec.md`: 画面仕様
- `docs/data-format.md`: データ形式
